# 智慧农业前端 — 协作约定

> 本文件是两个人协作前端时的「契约」。**共享文件不要改**，页面按约定写即可互通。

## 一、分工

| 负责人 | 页面 |
|--------|------|
| 我 | `control.html` 设备控制、`alarm.html` 告警管理、`assistant.html` 智能问答、`devices.html` 设备管理 ✅ |
| 同伴 | `login.html` 登录、`index.html` 数据总览、`monitoring.html` 数据监测、`history.html` 历史趋势 |

## 二、页面文件名约定（必须完全一致）

| 页面 | 文件名 | `body` 上的 `data-page` |
|------|--------|--------------------------|
| 数据总览 | `index.html` | `dashboard` |
| 数据监测 | `monitoring.html` | `monitoring` |
| 历史趋势 | `history.html` | `history` |
| 设备控制 | `control.html` | `control` |
| 告警管理 | `alarm.html` | `alarm` |
| 智能问答 | `assistant.html` | `assistant` |
| 设备管理 | `devices.html` | `devices` |
| 登录 | `login.html` | （登录页不用侧边栏，无需 `data-page`） |

> 侧边栏导航统一在 `layout.js` 里配置。**如果同伴改了文件名，只需改 `layout.js` 里 `NAV` 的 `href` 一处即可**，页面不用动。

## 三、共享文件（已写好，直接引用，勿改）

```
frontend/
├── assets/
```

## 四、同伴写页面的标准模板

每个页面（除登录页外）复制下面骨架，替换 `data-page` 和 `<main class="content">` 里的内容即可：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>数据监测 - 智慧农业平台</title>
  <link rel="stylesheet" href="assets/css/style.css">
</head>
<body data-page="monitoring">

  <div class="app">
    <aside class="sidebar" id="sidebar"></aside>
    <div class="main">
      <header class="topbar" id="topbar"></header>
      <main class="content">
        <!-- ★ 在这里写页面内容 ★ -->
      </main>
    </div>
  </div>

  <!-- 脚本引入顺序固定：mock → api → layout → 页面脚本 -->
  <script src="assets/js/mock.js"></script>
  <script src="assets/js/api.js"></script>
  <script src="assets/js/layout.js"></script>
  <script>
    Layout.init();          // 必须调用，注入侧边栏和顶栏
    // ... 页面逻辑 ...
  </script>
</body>
</html>
```

要点：
1. `body` 上写 `data-page="xxx"`（见上表），`Layout.init()` 会自动高亮导航 + 生成顶栏标题。
2. 脚本引入顺序**固定**：`mock.js` → `api.js` → `layout.js` → 页面自己的脚本。
3. 顶栏的用户名/角色会从 `localStorage` 自动读取。

## 五、数据调用方式（统一走 `window.API`）

| 方法 | 说明 | 返回 |
|------|------|------|
| `API.getPlots()` | 地块列表 | `{code, data:[{id,name,crop,area,temp,humidity,deviceCount,onlineCount}]}` |
| `API.getDevices()` | 设备列表 | `{code, data:[{id,name,type,plotId,plotName,online,controllable,running}]}` |
| `API.getRealtime(plotId)` | 单地块实时温湿度 | `{code, data:{plotId,plotName,temp,humidity,updatedAt}}` |
| `API.getHistory(plotId, days)` | 历史温湿度 | `{code, data:{dates:[], temp:[], humidity:[]}}` |
| `API.getThresholds()` | 阈值 | `{code, data:{humidityMin, tempMax}}` |
| `API.saveThresholds({humidityMin,tempMax})` | 保存阈值 | `{code}` |
| `API.getAlarms()` | 告警列表 | `{code, data:[{id,time,plotName,type,value,level,status}]}` |
| `API.updateAlarmStatus(id, status)` | 标记告警 | `{code}` |
| `API.controlIrrigation(deviceId, 'on'/'off')` | 灌溉开关 | `{code, data:device}` |
| `API.addDevice({name,type,plotId,plotName})` | 添加设备 | `{code, data:device}` |
| `API.unbindDevice(id)` | 解绑设备 | `{code}` |
| `API.getChatReply(question)` | 智能问答 | `{code, data:{answer, action}}` |
| `API.login(username, password, role)` | 登录 | `{code, data:{token,name,roleName,role}}` |

> 所有方法返回 Promise，`.then(function(res){ res.data ... })`。后端就绪后，把 `api.js` 里 `config.useMock` 改成 `false`、`config.baseUrl` 填后端地址即可，页面代码不用改。

## 六、登录态衔接（登录页必读）

登录成功后，同伴在 `login.html` 里调用：

```js
Layout.setUser({ name: '张老三', roleName: '农户', role: 'farmer' });
// 然后跳转
location.href = 'index.html';
```

其余页面顶栏会自动显示这个名字。角色对应：`farmer` 农户 / `admin` 农场管理员 / `sysadmin` 系统管理员。

## 七、ECharts（数据总览 / 历史趋势页用）

用 CDN 引入，放在 `<head>` 或 body 里（**在 `layout.js` 之前引入，别混在业务脚本前**）：

```html
<script src="https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js"></script>
```

- 历史趋势页：用 `API.getHistory(plotId, 7)` 拿 `dates/temp/humidity`，画两条折线（温度、湿度）。
- 数据总览页：可画一个实时温湿度小图，或直接用 `MOCK.plots` 渲染地块卡片（样式类 `.plot-card` / `.plot-metric` 已备好）。
- 离线环境：把 echarts.min.js 下载到 `assets/js/` 下，改成本地路径即可。
